# SpeedFast - Semana 8

Sistema de gestión de pedidos para la empresa SpeedFast.

## 🛠️ Tecnologías
- Java 17
- Swing (GUI)
- JDBC + MySQL
- Maven

## 📋 Funcionalidades
- CRUD completo de Repartidores
- CRUD completo de Pedidos (con filtros)
- CRUD completo de Entregas

## 🗄️ Base de datos
Base de datos: `speedfast_db`  
Script SQL incluido en `/db/script_estructura.sql`

## 🚀 Cómo ejecutar
1. Clonar el repositorio.
2. Ejecutar el script SQL en MySQL.
3. Configurar la contraseña en `ConexionDB.java`.
4. Ejecutar `Main.java`.
